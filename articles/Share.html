如何在git上挂一个博客（手机可用） 官方教程：https://docs.github.com/en/pages/quickstart
1. 在 git 创建一个新的库，库的名字为：<git用户名>.github.io
创建时勾选添加 README（添加自述文件）
2. 仓库名称-背景设定-代码与自动化-页面（像网页的小图标）
3. 构建与部署-源-从分支部署
4. 分支-选择分支，默认是 main
5. 创建一个 index.html 文件，在里面编辑页面
6. 地址为 https://<git用户名>.github.io
剩下的界面优化自由发挥，不会的可以问 AI
也可以下载我的，记得上传到自己的库里
或者你也可以直接复制我的库，但要记得把库的名字改成自己的
1. 找到我的库 https://github.com/baixueai-yiki/baixueai-yiki.github.io
2. 在绿色的按钮上面，点中间这个分叉的按钮
3. 仓库名称填 <自己的名字>.github.io
4. 点击创建

如何用c++写一个桌宠 这是一个以学习为目的进行的项目，其中大部分代码由ai编写，本人不享有知识产权
1. 首先需要安装一个 c++ 的开发环境，推荐使用 Visual Studio，下载地址：https://visualstudio.microsoft.com/zh-hans/downloads/
2. 安装完成后，打开 Visual Studio，选择创建一个新的项目，选择“控制台应用程序”，然后点击“下一步”
3. 输入项目名称和位置，然后点击“创建”。不过我这里用的是vs cord，没有创建项目这一步，是直接选择文件夹进行编辑的
4. 接下来，需要规划好项目的结构和设计方向。因为把代码全写在一个文件里会非常混乱，而且分好层也有利于区分功能。
我这里是这样的结构：
Source/
├─ Core/ # 工具层、基础设施
│ ├─ TextFile.h/cpp # 文本读取/写入、热更新
│ ├─ Path.h/cpp # 路径工具
│ ├─ Timer.h/cpp # 定时器工具
│ └─ Utils/ # 其他小工具类（JSON解析、日志等）
│
├─ Runtime/ # 调度层/中枢/事件系统
│ ├─ EventBus.h/cpp（负责模块间的消息发布与订阅）
│ ├─ Scheduler.h/cpp（定时器/调度器）
│ └─ StateManager.h/cpp（全局状态管理）
│
├─ Engine/ # 引擎层
│ ├─ Window/ # 窗口管理、消息循环
│ │ ├─ Window.h/cpp
│ │ └─ InputRouter.h/cpp
│ ├─ Render/ # 渲染逻辑
│ └─ Input/ # 输入事件
│ ├─ InputDispatcher.h/cpp
│ └─ InputChat.h/cpp
│
├─ Systems/ # 系统层
│ ├─ Pet/ # 核心桌宠系统
│ │ ├─ PetActor.h/cpp # PetActor + 状态、生命周期
│ │ └─ PetComponents/ # 桌宠组件
│ │ ├─ ChatComponent.h/cpp（桌宠发言）
│ │ ├─ AudioComponent.h/cpp（桌宠音频）
│ │ ├─ DiaryComponent.h/cpp（桌宠日记）
│ │ └─ InputComponent.h/cpp（输入文字）
│ │
│ ├─ UI/
│ │ ├─ UIActor.h/cpp # UIActo
│ │ ├─ UIComponents/ # UI组件
│ │ │ ├─ CloseComponent.h/cpp（关闭界面）
│ │ │ ├─ ScrollComponent.h/cpp（滚轮滑动）
│ │ │ ├─ DragComponent.h/cpp （拖动窗口）
│ │ │ └─ InputComponent.h/cpp（输入文字）
│ │ │
│ │ └─ UIPanels/ # UI界面
│ │ ├─ ChatPanels.h/cpp（聊天UI）
│ │ ├─ TaskPanels.h/cpp（任务UI）
│ │ ├─ SettingPanels.h/cpp（设置UI）
│ │ └─ OverlayPanels.h/cpp（浮层UI）
│ │
│ └─ Setting/ # 配置系统
│ ├─ Setting.h/cpp
│ └─ SettingWindowComponent.h/cpp
│
└─ Main/
└─ main.cpp # 启动入口
